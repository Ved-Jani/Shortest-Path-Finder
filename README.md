# IIT Guwahati Shortest Path Finder 🗺️

A modern, responsive web application that calculates the shortest path between any two locations on the IIT Guwahati campus using Dijkstra's algorithm.

## Features 🌟
- **Premium UI Design**: Beautiful dark-mode dashboard with glassmorphism panels and responsive layouts.
- **Dynamic Map Views**: Switch seamlessly between a high-resolution Campus Base Map, a Node Reference Network Graph, or view them Side-by-Side.
- **Accurate Pathfinding**: Uses a robust backend powered by Python and Flask to calculate distances and routes instantly.
- **Visual Timelines**: Path results are displayed as an elegant, sequential step-by-step node timeline.
